# Проектный офис

Веб-приложение для централизованного управления проектами, пользователями, заказчиками, оборудованием, программным обеспечением, документацией и историей изменений.

Проект разработан на Django в рамках учебной/преддипломной практики.

## Описание проекта

Система «Проектный офис» предназначена для хранения и сопровождения информации о проектах организации.  
Приложение позволяет вести список проектов, назначать ответственных сотрудников, хранить данные о заказчиках, учитывать оборудование и программное обеспечение, загружать проектную документацию и отслеживать историю изменений.

## Основные возможности

- авторизация пользователей;
- управление пользователями и ролями;
- просмотр списка проектов;
- создание и редактирование карточки проекта;
- хранение информации о заказчиках и компаниях;
- назначение руководителя проекта и ответственного за внедрение;
- учет статусов и тегов проектов;
- ведение контактов по проекту;
- учет проектного оборудования;
- учет производственного оборудования;
- хранение информации о программном обеспечении;
- ведение истории обновлений ПО;
- загрузка и хранение документов проекта;
- просмотр истории изменений.

## Роли пользователей

В системе предусмотрены следующие роли:

- администратор;
- руководитель проекта;
- внедренец;
- инженер;
- гость.
